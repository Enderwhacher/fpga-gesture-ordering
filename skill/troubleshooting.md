# 失败与定位清单

| 触发/观察 | 排查步骤 | 验证与失效边界 |
|---|---|---|
| 下载overlay后PL寄存器访问断连 | 先静态核对HWH、PS时钟分频、reset所有输入与极性；检查镜像PS参数 | 本项目修正aux reset被固定为有效电平；其他板不可直接套本PS参数 |
| base视频正常，加载独立卷积bit后HDMI失效 | 检查是否先后加载完整bitstream，后者会替换PL | 统一硬件设计或外移显示；本版选择笔记本HDMI |
| 算子快但整机几乎不快 | 记录检测/前后段/打包/DMA/显示，确认局部占比 | 两块1.81倍不等于整机1.81倍；公平CPU对照仍须保留 |
| 4线程比3线程慢 | 在真实采集预览下比较，不只测空载；分开后台库与DNN线程配置 | 本板第四版3线程胜出，不保证其他CPU相同 |
| 流水线更高FPS却更难交互 | 分别看源图年龄、P95、输出间隔，检查队列长度/丢弃计数 | 本轮流水线被否决，最终串行，不把参数bank说成视频双buffer |
| Notebook跑完后App package mismatch | 检查是否把可变输出Notebook列为固定哈希 | Notebook允许变化，其余源码/参数仍校验；不整体关闭验证 |
| vendor存在但installed.json缺失 | 说明未完成；不要直接当成已安装或删除系统目录 | 暂存目录完整解压+校验再改名启用，备份部分目录 |
| 持续手势重复操作 | 检查是否把同一seq或预览帧多次送入状态机 | 新结果与明确无手释放，断线不是释放 |
| CPU/FPGA识别都差 | 先核对模型/预处理/方向、同图数值，再查加速器 | 本项目曾以物理相机方向解决问题，不盲改标签顺序 |

每次记录：触发输入/版本/错误原文、最小复现、提出假设、实际修复、黄金参考、板上测量和未覆盖边界。未运行或中断不记为通过。
